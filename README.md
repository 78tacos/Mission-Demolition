# Mission Demolition

A 3D slingshot game. Drag on the slingshot to aim, release to fire, and knock down each castle. Clearing a castle loads the next one. After the last castle, the game-over scene can restart the run.

Open this folder in Unity 2021.3.33f1 (the version in `ProjectSettings/ProjectVersion.txt`). The playable scene is `Assets/Scenes/_Scene_0.unity`. A WebGL build is in `WebGL Builds/`.
